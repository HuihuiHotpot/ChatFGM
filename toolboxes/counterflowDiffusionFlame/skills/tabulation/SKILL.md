# Tabulation

由 [case-dict](../case-dict/SKILL.md) 核对本次任务的准入条件，按用户确认的工况和步骤执行。

## General Principles

### 已有产物的核对、复用和重做

准备使用已有产物时，先确认它对应的工况、制表步骤和输入来源。对照当前 `caseDict` 和本次任务，核对影响该步骤的设置，再按对应参考文档检查产物。核对通过后直接复用。

只有缺少会影响复用判断的信息时，才向用户询问具体缺哪一项。补齐并核对通过后，再使用该结果。用户提供的外部结果尚未放到对应目录时，请用户按标准算例的目录结构放好结果文件和核对所需的记录。

需要重做且已有产物时，先向用户说明要重做的工况和步骤、需要处理的旧产物，以及可能受影响的下游结果。经用户确认后，按对应步骤的参考文档处理本步骤的旧产物。参考文档无具体约定时，按确认的范围，将待重做的旧产物移出对应步骤的产物目录作为备份，或删除。下游产物按[重做后检查下游产物](#重做后检查下游产物)核对后再处理。

### 重做后检查下游产物

用户主动要求的重做和排查问题后的重做，都要在核对本步结果后立即检查是否有后续产物用过旧结果。有的话，逐项判断是否仍可用。

确认有文件不能继续使用时，先告诉用户哪些文件受影响、为什么不能再用。经用户确认后，在确认范围内将这些文件移出对应步骤的产物目录作为备份，或删除。

## Execution

### 确定执行范围

先明确用户本次想完成的工作，读取当前算例的 `0-caseDict/caseDict`，并查看已有的 Stage C 产物（如有）。对照 `Tabulation Workflow`，按工况判断哪些步骤已有可用结果、哪些仍需执行。

用户指定做到某一步时，以该步为目标，将所需且尚无可用结果的前置步骤纳入执行范围。用户调整目标时，重新确定执行范围。

确定拟执行的步骤后，查阅对应参考文档，核对该步所需输入，并明确预期产出。

开始执行前，向用户简要说明本次涉及哪些工况、要完成哪些步骤、准备复用哪些已有结果，以及剩余步骤的执行顺序。

### 执行选定步骤

按 `Tabulation Workflow` 中的依赖顺序执行本次选定的步骤。执行每个步骤前，查阅该步骤对应的参考文档，并按其中的说明核对输入、调用工具和检查结果。

执行中涉及重做时，核对本步重做结果后，立即按[重做后检查下游产物](#重做后检查下游产物)处理，再继续下一步。

## Tabulation Workflow

`00` 按需开展。制表按 `01 → 02 → 03 → 04 → 05` 的顺序推进，其中 `04` 同时使用 `02` 和 `03` 的结果。

### 00 候选 Yc 单调性预实验（选做）

- **前置结果**为 Stage B 的制表清单、所选工况中包含 `Z` 和 `Y` 的原始剖面，以及配套的反应机理。
- **产出**为交互式 HTML 报告，用于比较候选定义并查看每一步回折。
- 执行前查阅[候选 Yc 单调性预实验](references/yc-pretest.md)。

### 01–05 制表

按以下依赖顺序执行本次选定的步骤。

#### 01 准备制表样本

- **前置结果**为 Stage B 的制表清单、拟用于制表的原始剖面，以及配套的反应机理。
- **产出**为各工况在原网格上的制表样本，每条剖面对应一份 HDF5。工况说明记录在 `case.md`。
- 执行前查阅[准备制表样本](references/prepare-samples.md)。

#### 02 沿 Z 插值

- **前置结果**为 `01` 中该工况的逐剖面制表样本。
- **产出**为插值到同一套目标 `Z` 网格的逐剖面 HDF5。
- 执行前查阅[沿 Z 插值](references/build-tables.md#02-沿-z-插值)。

#### 03 计算 Yc 上下界

- **前置结果**为 `02` 中该工况在目标 `Z` 网格上的全部制表剖面。
- **产出**为该工况的 `yc_bounds.h5`，保存各 `Z` 点的 `Yc_min` 和 `Yc_max`。
- 执行前查阅[计算 Yc 上下界](references/build-tables.md#03-计算-yc-上下界)。

#### 04 计算 C

- **前置结果**为 `02` 中该工况的逐剖面 HDF5，以及用同一批剖面计算得到的 `03` 上下界。
- **产出**为新增归一化进度变量 `C` 的逐剖面 HDF5。
- 执行前查阅[计算 C](references/build-tables.md#04-yc-归一化为-c)。

#### 05 沿 C 插值

- **前置结果**为 `04` 中该工况已归一化的制表剖面。
- **产出**为该工况的 `Z–C` 表。每个目标 `C` 对应一份 `prof_c*.h5`，包含该 `C` 下整套 `Z` 网格上的表格数据。
- 执行前查阅[沿 C 插值](references/build-tables.md#05-沿-c-插值)。

## Completion and Handoff

本次工作结束后，按用户确认的范围核对完成情况。向用户说明完成了哪些步骤和工况、可用结果放在哪里，以及还有哪些事项未完成、原因是什么。通过 `case-dict` 更新相关算例记录。

本次任务开展 `Yc` 单调性预实验时，向用户提供 HTML 报告的路径和测试覆盖的工况范围。完成制表时，按工况提供 `03` 的 `Yc` 上下界和 `05` 的 `Z–C` 表的路径。

用户要求继续时，回到 `case-dict` skill，根据用户目标和已有产物确定下一阶段，并检查该阶段的准入条件。
