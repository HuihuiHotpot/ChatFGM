# 原始剖面字段

本表记录本工具箱一维对冲扩散火焰剖面的 HDF5 字段。`N_x` 为 `x` 中的空间网格点数，`N_s` 为配套机理的物种数。含物种维度的字段按机理中的物种顺序保存。

Ember 的输出选项决定扩展字段的保存范围。`heatReleaseRate` 控制 `q` 和 `rho`，`timeDerivatives` 控制时间导数诊断字段，`extraVariables` 控制物种净生成率、其余热物性以及下表中的网格和扩散字段。`Z` 由 Stage B 后处理补写。

## 工况与状态

| HDF5 字段 | 物理含义 | 单位 | 保存形状 |
| --- | --- | --- | --- |
| `x` | 沿剖面法向的一维空间坐标 | `m` | `(N_x,)` |
| `T` | 温度 | `K` | `(N_x,)` |
| `Y` | 各物种质量分数 | `kg/kg` | `(N_s, N_x)` |
| `U` | 切向速度梯度，Ember 的相似变量 \(U=ua/u_\infty\) | `1/s` | `(N_x,)` |
| `V` | 垂直于火焰的质量通量 \(\rho v\)，其中 \(v\) 为法向速度 | `kg/(m^2*s)` | 一维数组 |
| `P` | 工况的热力学压力 | `Pa` | 标量 |
| `a` | 当前时刻施加的应变率 \(a(t)\) | `1/s` | 标量 |
| `dadt` | 施加的应变率对时间的导数 | `1/s^2` | 标量 |
| `t` | 保存剖面时的求解时间 | `s` | 标量 |
| `fileNumber` | Ember 写出器的当前剖面编号 | 无量纲整数 | 标量 |
| `gridAlpha` | 网格几何指数 \(\alpha\)。非圆柱配置取 `0`，圆柱配置取 `1` | 无量纲整数 | 标量 |
| `Z` | 根据 C、H、O 元素组成计算的 Bilger 混合分数，由 Stage B 补写 | 无量纲 | `(N_x,)` |

## 热物性与化学源项

| HDF5 字段 | 物理含义 | 单位 | 保存形状 |
| --- | --- | --- | --- |
| `rho` | 混合物密度 | `kg/m^3` | `(N_x,)` |
| `cp` | 混合物质量定压比热容 | `J/(kg*K)` | `(N_x,)` |
| `mu` | 混合物动力黏度 | `Pa*s` | `(N_x,)` |
| `k` | 混合物热导率 | `W/(m*K)` | `(N_x,)` |
| `W` | 各物种的摩尔质量 | `kg/kmol` | `(N_s,)` |
| `Wmx` | 混合物平均摩尔质量 | `kg/kmol` | `(N_x,)` |
| `rhoD` | 密度与各物种基于质量分数梯度的混合物平均扩散系数之积 \(\rho D_{k,m}\) | `kg/(m*s)` | `(N_s, N_x)` |
| `wdot` | 各物种的体积净摩尔生成率 | `kmol/(m^3*s)` | `(N_s, N_x)` |
| `q` | 单位体积的化学热释放率 \(q=-\sum_k\dot{\omega}_k\bar h_k\)，其中 \(\bar h_k\) 为物种偏摩尔焓 | `W/m^3` | `(N_x,)` |

## 网格与扩散通量

| HDF5 字段 | 物理含义 | 单位 | 保存形状 |
| --- | --- | --- | --- |
| `hh` | 相邻网格点间距 \(x_{j+1}-x_j\) | `m` | `(N_x-1,)` |
| `cfm` | 非均匀网格三点中心差分中，一阶空间导数的左点系数 | `1/m` | `(N_x-1,)` |
| `cf` | 同一差分公式的中心点系数 | `1/m` | `(N_x-1,)` |
| `cfp` | 同一差分公式的右点系数 | `1/m` | `(N_x-1,)` |
| `rphalf` | 相邻网格点之间的几何因子 \(\big[(x_j+x_{j+1})/2\big]^\alpha\) | `gridAlpha=0` 时无量纲，`gridAlpha=1` 时为 `m` | `(N_x-1,)` |
| `jFick` | 相邻网格点之间由质量分数梯度产生的各物种 Fick 扩散质量通量 | `kg/(m^2*s)` | `(N_s, N_x)` |
| `jSoret` | 相邻网格点之间由温度梯度产生的各物种 Soret 扩散质量通量 | `kg/(m^2*s)` | `(N_s, N_x)` |
| `jCorr` | 用于修正各物种扩散质量通量之和的通量，按界面质量分数分配给各物种 | `kg/(m^2*s)` | `(N_x,)` |

索引从 `0` 开始。Ember 在内部节点 `j=1,…,N_x-2` 计算 `cfm`、`cf` 和 `cfp`。`jFick`、`jSoret` 和 `jCorr` 按 `N_x` 保存，相邻网格面的索引范围是 `j=0,…,N_x-2`。

## 时间导数诊断

`Conv`、`Diff` 和 `Prod` 分别表示对流、扩散和源项分裂步的贡献。Ember 用相应分裂步的累计增量除以全局时间步长，再扣除该步的分裂常数，得到这些诊断量。

| HDF5 字段 | 物理含义 | 单位 | 保存形状 |
| --- | --- | --- | --- |
| `dUdtConv` | 对流分裂步对 `U` 变化率的贡献 | `1/s^2` | `(N_x,)` |
| `dUdtDiff` | 扩散分裂步对 `U` 变化率的贡献 | `1/s^2` | `(N_x,)` |
| `dUdtProd` | 源项分裂步对 `U` 变化率的贡献 | `1/s^2` | `(N_x,)` |
| `dTdtConv` | 对流分裂步对温度变化率的贡献 | `K/s` | `(N_x,)` |
| `dTdtDiff` | 扩散分裂步对温度变化率的贡献 | `K/s` | `(N_x,)` |
| `dTdtProd` | 源项分裂步对温度变化率的贡献 | `K/s` | `(N_x,)` |
| `dTdtCross` | 物种扩散所携带的焓对温度变化率的贡献 | `K/s` | `(N_x,)` |
| `dYdtConv` | 对流分裂步对各物种质量分数变化率的贡献 | `1/s` | `(N_s, N_x)` |
| `dYdtDiff` | 扩散分裂步对各物种质量分数变化率的贡献 | `1/s` | `(N_s, N_x)` |
| `dYdtProd` | 源项分裂步对各物种质量分数变化率的贡献 | `1/s` | `(N_s, N_x)` |
| `dYdtCross` | Soret 扩散通量和扩散修正通量对各物种质量分数变化率的贡献 | `1/s` | `(N_s, N_x)` |
| `dWdt` | Ember 对流子系统中混合物平均摩尔质量的时间导数 | `kg/(kmol*s)` | `(N_x,)` |
| `drhodt` | Ember 根据温度和组分变化率计算、用于连续方程的密度时间导数 | `kg/(m^3*s)` | `(N_x,)` |
