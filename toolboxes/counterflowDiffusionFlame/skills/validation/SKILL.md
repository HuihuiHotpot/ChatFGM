# Validation

## Inputs

- **制表样本。** `C-tabulation/01-prepared_samples/` 中按工况保存的 HDF5 样本。
- **Yc 上下界。** `C-tabulation/03-yc_bounds/` 中按工况保存的 `yc_bounds.h5`。
- **Z–C 表。** `C-tabulation/05-c_interpolated/` 中按工况保存的 `prof_c*.h5` 切片。

## General Principles

### 已有产物的核对、复用和重做

准备使用已有产物时，先确认其对应的工况和来源。对照当前 `caseDict` 和本次任务，核对与验证有关的设置。复用已有验证结果时，还需核对该结果所用的参考样本和制表结果。核对通过后直接复用。

只有缺少会影响复用判断的信息时，才向用户询问具体缺哪一项。补齐并核对通过后再使用。用户提供的外部结果尚未放到对应目录时，请用户按标准算例的目录结构放好结果文件和核对所需的记录。

需要重做且拟使用的输出目录中已有验证结果时，先向用户说明本次重做的范围、需要处理的旧报告，以及可能受影响的下游产物。经用户确认后，将该目录中已有的 `validation_results.json` 和 `validation.html` 移出作为备份，或删除。下游产物按[重做后检查下游产物](#重做后检查下游产物)核对后再处理。

### 重做后检查下游产物

用户主动要求的重做和排查问题后的重做，都要在核对本步结果后立即检查是否有后续产物用过旧结果。有的话，逐项判断是否仍可用。

确认有文件不能继续使用时，先告诉用户哪些文件受影响、为什么不能再用。经用户确认后，在确认范围内将这些文件移出对应步骤的产物目录作为备份，或删除。

## Execution

仅查看已有验证报告时，在 ChatFGM 工作台中打开对应报告。需要依据已有报告作出用表判断时，按[已有产物的核对、复用和重做](#已有产物的核对复用和重做)核对通过后，直接进入第 3 步。

### 1. 确定验证范围并生成配置

1. **选取代表工况。** 用户已指定工况时，按指定范围选取。否则，Agent 从本次验证范围内已完成制表的工况中，结合查表轴取值和工况差异，选取有代表性的工况，并说明依据。

2. **选取参考剖面。** 从每个入选工况的 `C-tabulation/01-prepared_samples/<case_name>/` 中选取完整的 HDF5 样本。用户已指定剖面时，使用与之对应的制表样本。否则，Agent 结合本次验证目标和已有样本选取，可考虑瞬态着火的不同阶段、稳态延拓的不同应变率或 FFM 的不同松弛阶段，并说明所选样本的代表性。需要核对剖面来源时，查看样本的 `source_profile` 属性。

3. **生成验证配置。** 将实际选中的工况和样本写入 `D-validation/validation_inputs.json`。`case_name` 使用 Stage C 的完整工况目录名，`samples` 填写该工况下选中样本相对于算例根目录的路径。

4. **记录选样设置。** 根据本次生成的验证配置和选样依据，通过 `case-dict` 将工况数量、各工况的剖面数量及选取方式写入 `caseDict.validation`。

以下为配置示例。

```json
{
  "cases": [
    {
      "case_name": "Tf=300 K_To=1600 K_p=101325 Pa_a=300 s-1",
      "samples": [
        "C-tabulation/01-prepared_samples/Tf=300 K_To=1600 K_p=101325 Pa_a=300 s-1/transient_ignition__prof000055.h5",
        "C-tabulation/01-prepared_samples/Tf=300 K_To=1600 K_p=101325 Pa_a=300 s-1/transient_ignition__prof000078.h5",
        "C-tabulation/01-prepared_samples/Tf=300 K_To=1600 K_p=101325 Pa_a=300 s-1/steady_flame_continuation__prof_eps0200.h5"
      ]
    }
  ]
}
```

### 2. 运行先验验证工具

在当前算例根目录，使用 ChatFGM 工作台配置的 Python，按第 1 步生成的验证配置调用工具。

```powershell
& $env:CHATFGM_PYTHON (Join-Path $env:CHATFGM_TOOLBOX_DIR 'tools/validation/validate_fgm_table.py') `
    --inputs 'D-validation/validation_inputs.json'
```

### 3. 分析验证结果并作出用表判断

在 ChatFGM 工作台中打开本次要分析的 `validation.html`。新生成的报告位于 `D-validation/validation.html`。

1. **明确本次用表需要复现什么。** 根据用户目标和 `caseDict`，确定应重点关注的输出量、工况和燃烧阶段。用户已明确验收要求时，按该要求判断。其余情况，结合本次要研究的燃烧特征或要比较的工况差异，说明采用的判断依据。

2. **判断表保留了哪些关键特征。** 结合对比曲线、最大绝对误差和活跃区归一化平均绝对误差，比较同一变量在不同工况和剖面上的表现。结合参考值的量级和工况间的差异，判断查表偏差是否足以改变用户关心的结论。涉及坐标截断时，结合截断记录判断其与主要偏差的关系。

3. **主动查证会改变决定的问题。** 根据偏差的位置、形态及其在不同剖面上的表现，提出可能原因，主动对照相关设置、参考样本和制表中间产物。按需联网查阅相关论文、技术资料或工具文档，并核对其对本算例的适用性。几种解释会导向不同的用表决定或返工方案时，优先完成最能区分它们的可行检查。只有缺少会改变决定且无法自行获取的信息时，才向用户询问具体缺项。证据足以支持用表决定和必要的返工建议时，结束排查。

4. **给出明确的用表决定和推荐方案。** 直接回答这张 FGM 表能否支撑本次目标、在哪些工况或燃烧阶段可以使用、是否需要重做，并说明主要依据。需要重做时，根据查证结果推荐从哪个阶段的哪一步开始、具体调整什么、哪些下游产物需要更新，以及用哪些样本和变量复验。

完成本次用表判断后，通过 `case-dict` 在 `intent.decisionLog` 中记录结论、适用范围和主要依据，并注明所依据的验证报告路径及其对应的 `Yc` 上下界和 `Z–C` 表路径。建议重做时，一并记录建议从哪个阶段的哪一步开始。

按用户确认的方案，从确定的阶段和步骤开始重做。需要回到上游阶段时，通过 `case-dict` 核对该阶段的准入条件，再按对应阶段的 skill 执行。从 Stage D 开始重做时，按本 skill 的[已有产物的核对、复用和重做](#已有产物的核对复用和重做)处理。

## Failure Handling

发现调用失败，先告诉用户目前看到的问题、影响范围，以及接下来准备检查什么。

- **工具调用失败。** 查看 `stderr`，根据报错核对验证配置、对应工况的制表产物、输出目录或 Python 环境。暂停依赖本次验证结果的后续工作。

向用户说明排查结果和处理建议。需要用户补充信息或确认方案时，按工具箱 `AGENTS.md` 的规则与用户确认，再按确认的范围处理。通过 `case-dict` 更新相关错误记录和已确认的算例设置。

问题解决后，按本次确认的完整配置重新运行。需要调整验证范围时，先更新同一份 `validation_inputs.json`，再同步 `caseDict.validation`。拟使用的输出目录中已有验证报告时，按[已有产物的核对、复用和重做](#已有产物的核对复用和重做)处理后再运行。

## Method Notes

### 回查坐标截断

逐点回查时，`Z` 和 `C` 共用同一截断规则。小于 `0` 时用 `0`，大于 `1` 时用 `1`，其余保留原值。

1. **先处理 `Z`。** 剖面两端的入口 `Z` 若因浮点舍入略偏离端点，按对应的入口坐标回查。查表 `Z` 为 `0` 或 `1` 时，`Yc` 上下界重合，无法计算归一化的 `C`。同一侧入口值在所有 `C` 切片中相同，因此工具取 `C=0` 作为查表坐标，结果记录中的 `C` 留空。
2. **再处理 `C`。** 对查表 `Z` 位于 `0 < Z < 1` 的点，用该采样点的 `Yc` 和对应 `Z` 处的 `Yc` 上下界计算 `C`，按同一规则截断后查表。

保留原始坐标和用于查表的坐标，分别标记和汇总 `Z`、`C` 的截断点。入口浮点舍入单独处理。截断点用表返回的边界值与同一采样点的参考值计算误差。

### 误差指标

对每条参考剖面的每个待验证变量，在原始采样点计算残差，即查表值减去同一点的参考值。发生 `Z` 或 `C` 截断时，使用表边界返回的值计算残差，照常纳入统计。

#### 最大绝对误差

取整条剖面上绝对残差的最大值，报告误差值、变量原单位及对应的 `Z`，用于定位偏差最大的采样点。

#### 活跃区归一化平均绝对误差

该指标衡量活跃区内的平均绝对偏差，以该变量在整条参考剖面上的峰值幅度为基准，用百分比表示。

**文献方法。** Schepers 和 van Oijen（2025）对二维详细化学参考场逐点回查 FGM 表，分别评估进度变量源项和 H 自由基质量分数。他们用各变量在详细化学参考场中的最大值归一化误差，以一维火焰的进度变量源项峰值乘以 `0.165` 作为划定反应区的阈值，并在该区域内对归一化误差的绝对值取面积平均。[论文第 3.2 节](https://pure.tue.nl/ws/portalfiles/portal/365274566/1-s2.0-S0010218025003694-main.pdf#page=7) · [图 3](https://pure.tue.nl/ws/portalfiles/portal/365274566/1-s2.0-S0010218025003694-main.pdf#page=8)

**Stage D 的计算方法。** 对一维参考剖面沿 `Z` 做长度加权平均。

1. **划定活跃区。** 读取 `01` 参考样本中保存的带符号源项 `omega_Yc`。以该剖面正源项峰值的 `16.5%` 为阈值，取源项高于阈值的所有 `Z` 区间。相邻采样点跨过阈值时，用线性插值确定区间边界。
2. **确定归一化基准。** 对每个变量 $v$，取它在整条参考剖面上的峰值幅度 $\max_i |v_{\mathrm{ref},i}|$。
3. **计算区间平均。** 在相邻采样点之间对带符号残差做线性插值，沿各活跃区间对残差的绝对值积分。将积分之和除以活跃区总 `Z` 长度与该变量参考峰值幅度的乘积，再乘以 `100` 得到百分比。

同一条参考剖面的各变量共用活跃区。用同一份参考样本比较采用相同 `Yc` 定义的多张表时，沿用该样本确定的活跃区和参考峰值。整条剖面没有正源项、活跃区总长度为零或变量的参考峰值幅度为零时，该指标显示 `—`。
