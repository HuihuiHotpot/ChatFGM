# 自由传播预混火焰工具箱

## 适用范围

本工具箱面向一维自由传播预混火焰（freely propagating premixed flame）的 Flamelet 生成流形（FGM）建模。适用于需要以自由传播构型建立预混火焰热化学数据库的任务。

## 工作原则

1. 先查看项目当前的真实文件与配置，再决定后续步骤；不假设案例目录、机理文件或工况数值。
2. 专业计算、建表、后处理与报告逻辑由本工具箱 `tools/` 下的脚本承担，`skills/` 中的技能说明负责调用方式。
3. 本工具箱的 AGENTS.md、skills、tools 始终在原位加载，不复制到项目或 CODEX_HOME，也不覆盖项目自身的 AGENTS.md。
4. Python 解释器由依赖设置中为该工具箱配置的运行环境提供；执行时使用该环境的真实解释器（`CHATFGM_PYTHON`），不退回系统 Python，不需要手动 activate。
5. 缺少专业依赖或工具时明确说明原因，不编造计算结果或成功状态。
