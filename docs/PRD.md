# ChatFGM 产品需求文档

版本：1.0 · 日期：2026-10-29 · 平台：Windows 桌面端

## 1 产品定位

ChatFGM 是自然语言驱动的 Flamelet Generated Manifold（FGM）全流程工作台，面向燃烧计算研究与工程用户，将项目文件、Agent 协作和结果查看整合在一个窗口中。

核心流程：创建或打开项目 → 配置工况与机理 → 执行 Flamelet 计算 → 生成流形表 → 查看结果与报告。具体计算流程由所选 Flamelet 工具箱提供。

当前已验收前端 UI；真实文件操作、模型服务、计算执行及持久化属于后端接入范围。演示数据和模拟失败入口不作为正式产品功能。

## 2 界面基线

以以下文件的已验收界面和交互为准：

- 最终 UI：`E:\Desktop\ChatFGM\references\UI原型\index.html`
- 视觉规范：同目录 `DESIGN.md`。

保持现有 Shadcn 风格：白色内容区、暖灰分层、细边框、克制阴影，少量低饱和橙红强调。火焰 Logo 保留原形状；成功、警告和失败使用独立语义色。两个灰度参考项目保持不变。

## 3 窗口与项目

一个窗口只展示一个项目，包含欢迎页和项目工作台两种状态。

| 区域 | 功能 |
| --- | --- |
| 顶部应用栏 | ChatFGM 名称菜单提供新建、打开和关闭项目；右侧为左右面板开关及设置入口 |
| 左侧项目目录 | 展示当前项目的真实文件夹与文件 |
| 中央工作区 | 使用标签页打开文件；无标签时显示“工作区”和简短提示 |
| 右侧对话 | 管理当前项目的多段独立对话及 Agent 任务 |
| 底部状态栏 | 左侧显示项目名称，悬停显示完整路径，点击复制；右侧显示 Codex CLI 连接状态 |

左右面板可独立调整宽度和完全隐藏，隐藏后不保留窄条；通过顶部按钮恢复。最小支持宽度为 800px。

### 项目操作

| 操作 | 规则 |
| --- | --- |
| 欢迎页 | 显示产品介绍、新建项目、打开项目及最近项目；未打开项目时不能对话 |
| 新建项目 | 选择项目文件夹和 Flamelet 类型；无单独项目名称字段，名称取文件夹名 |
| 初始化 | 将对应工具箱的 `standardCase` 直接初始化到所选文件夹，不再增加一层目录 |
| 打开项目 | 使用系统文件夹选择器；先选择目标，再处理当前项目退出确认；取消不影响当前项目 |
| 重复打开 | 选择当前项目目录时保持现有状态，不重复初始化 |
| 关闭项目 | 返回欢迎页，保留磁盘文件和已保存的项目记录 |

欢迎页和应用菜单复用同一新建流程。项目打开与文件浏览不依赖 Codex CLI 或模型服务连接。

### 离开当前项目

新建其他项目、打开其他项目和关闭项目，只要当前已有项目，都必须确认。

- 有未保存文件时，提供“保存并继续”“不保存并继续”“取消”。
- 有运行任务时，等待任务结束，或成功停止后再继续；确认期间同步任务状态，不自动跳转。
- 保存、停止、创建或打开失败时保留当前项目和相关输入，说明原因并允许重试。
- 初次进入项目时中央工作区为空；再次返回项目时恢复其工作状态。

## 4 项目目录与文件查看

目录结构来自真实项目和工具箱模板，不将计算阶段硬编码为导航。标准 Case 示例为：`0-caseDict`、`A-mechanism`、`B-preRuns`、`C-runs`、`D-tabulation`、`E-post`、`F-reports`。

目录树支持展开、折叠、选中及右键操作：打开、新建文件或文件夹、剪切、复制、粘贴、重命名、删除、复制路径、在资源管理器中显示、添加到对话。菜单按对象类型提供适用操作，删除前确认。

重命名和移动同步更新标签及对话引用；删除后引用显示失效。添加到对话的文件或文件夹以可移除引用展示，同一对象不重复添加。

### 六类查看器

| 类型 | 展示与交互 |
| --- | --- |
| 文本与代码 | 可编辑、行号与语法显示；手动保存，支持 Ctrl+S |
| Markdown | 预览与源码切换；白纸式阅读，支持标题、列表、表格、代码和公式；源码可编辑保存 |
| 图片 | 保持比例，支持缩放、适应视区及平移查看 |
| CSV | Excel 式只读网格，列字母、行号、单元格选择和原值查看；首行保留为原始数据，不另造业务表头 |
| HTML | 嵌入网页，支持刷新；保留网页自身样式、交互及标签切换前的状态 |
| H5 | 只读查看数据集、类型、维度和原值；支持标量、一维及二维数据；不支持的类型给出提示 |

同一文件只打开一个标签；未保存修改有标记，关闭时确认。切换标签不丢失编辑和查看状态，长代码与宽表格仅在查看器内部滚动。

H5 通常对应一个时刻的 Flamelet profile。工作台负责通用数据查看；组分解释、曲线及高级后处理由工具箱的 skills 和 tools 生成网页，再嵌入工作区。

## 5 Agent 对话

通过 Codex CLI app-server 连接 Agent。一个项目允许多段独立对话，支持新建、历史切换和任务状态查看。

每段对话独立保存：消息记录、草稿、附件与文件引用、模型、推理强度、权限模式及任务状态。切换对话或项目不得串用这些内容。

| 控件 | 规则 |
| --- | --- |
| 添加 | 添加文件、图片或截图；允许只有附件或引用的消息 |
| 权限 | 提供只读、项目内读写、完全访问；与实际运行权限一致 |
| 模型 | 根据实际服务展示可用模型 |
| 推理强度 | 独立控件；切换模型后恢复该模型默认强度，并更新可选项 |
| 发送与停止 | Enter 发送，Shift+Enter 换行；输入法确认不触发发送；运行期间提供停止操作 |

不提供语音输入。连接不可用时明确说明发送受限原因，保留草稿并提供恢复入口。

用户消息采用浅色气泡，Agent 回复使用 Markdown；工具调用与服务返回的执行摘要采用浅灰文字，可展开查看。用户阅读历史内容时不强制滚到底部，提供“回到最新”。

仅在服务提供分步计划时展示步骤进度，准确区分运行、完成、失败和停止。普通问答结束后不保留执行摘要。

### 后台任务通知

仅当任务所在对话不可见时，对完成、失败或停止发出通知；当前可见对话在消息区直接显示状态。开始和进度更新不弹通知，事后切换对话不补发。

通知位于中央工作区底部居中，显示对话、结果及“查看”，不抢焦点、不遮挡输入。点击查看恢复对应对话；进入该对话后消除提醒。普通通知约 4 秒消失，后台任务通知约 7 秒；关闭项目时清除。模态弹窗打开期间不可穿透操作通知。

## 6 依赖设置

设置为全局配置，分为以下三类；提供保存、取消、检测结果及失败重试。

| 分类 | 内容 |
| --- | --- |
| Codex CLI | 可执行文件位置、浏览、检测与连接、版本和状态 |
| 模型服务 | ChatGPT 登录与退出；自定义 API 的新增、编辑、删除、连接测试和当前服务选择；配置名称、地址和密钥，密钥默认遮罩 |
| Flamelet 工具箱 | 自动扫描固定位置的工具箱，可刷新；为每个工具箱配置一个运行环境并检测，环境配置彼此独立 |

工具箱示例：`counterflowDiffusionFlame`、`freelyPropagatingPremixedFlame`。用户可按约定扩充类型。创建项目时绑定所选工具箱的 `AGENTS.md`、skills 和 tools。求解程序在所配环境中编译与执行，不另拆 Python 和求解器配置项。

修改配置后旧检测结果失效；检测期间避免重复提交，取消后旧异步结果不得覆盖已保存配置。模型与强度仍在对话中选择。Markdown、图片、CSV、HTML、H5 的基础查看能力由应用提供，不增加用户依赖设置项。

## 7 状态保存与后端接入

| 范围 | 接入要求 |
| --- | --- |
| 文件与项目 | 原生目录选择、文件读写和目录操作；同步树、标签与引用 |
| Agent | app-server 对话、工具调用、任务进度、权限审批、停止与错误状态 |
| 模型服务 | 登录、自定义 API 连接及模型能力适配；妥善保存密钥 |
| 工具箱 | 扫描、模板初始化、资源绑定和环境内任务执行 |
| 持久化 | 项目与最近记录、工作区、对话及其独立设置、草稿、全局配置；重启后恢复已保存内容 |
| 查看器 | 真实文件解析、资源加载和网页嵌入，处理加载失败及不支持类型 |

所有操作必须以真实结果更新状态；失败或取消不伪装成功，不丢失未提交内容。程序重启后核实任务状态，不将旧任务直接显示为仍在运行。

## 8 验收标准

- 新建、打开、关闭、取消和失败重试流程完整；文件修改和运行任务按规则处理。
- 六类文件正确打开；文件操作与标签、引用同步；手动保存结果可从磁盘验证。
- 多项目、多对话的内容和设置互不混用，重启后按保存结果恢复。
- 真实 Agent 可发送、停止、显示进度及审批；前台状态和后台通知符合规则。
- 三类设置能够保存、检测和恢复；取消不受旧请求回调影响。
- 在 800、1000、1440px 宽度下操作可达，弹窗、通知、菜单不遮挡关键控件，无整页横向溢出。
- 保持已验收的视觉规范，焦点、禁用及错误状态可辨识。

本期不扩展多人协作、云端项目管理或工作台内置专业绘图；计算方法和专业后处理继续由 Flamelet 工具箱承载。
