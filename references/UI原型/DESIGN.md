# ChatFGM 界面配色规范

第一轮：低饱和赤陶橙红方向。基线为灰阶工作台（`6d9986f8…/index.html`），本轮的改动只有两件事——**换一套颜色 token** 和 **接入重新着色的图标**；栅格、字号、间距、圆角、控件密度、交互行为与文案全部沿用基线。

本轮只覆盖主工作台及其共享组件（顶栏、项目目录、标签条、六类查看器、对话栏、输入区、状态栏、各类弹层）。欢迎页与营销位不在重设计范围内，仅继承同一套 token，因此只出现主按钮与图标两处品牌色。

## 1. 四层颜色结构

改色不靠逐条改样式，而是把灰阶基线里散落的 300 余处颜色字面量收敛成四层：

| 层 | 作用 | 变量 |
| --- | --- | --- |
| 中性阶 | 所有表面、描边、文字 | `--n-25 … --n-950` |
| 品牌 | 唯一的交互信号色 | `--brand` 及其 hover/active/soft/line/ink |
| 语义 | 成功 / 警告 / 失败，**不参与品牌色系** | `--success*`、`--warning*`、`--danger*` |
| 角色 | 组件实际引用的语义别名 | `--bg-page/panel/raised/hover/active`、`--line/line-soft/line-strong`、`--text/text-muted/text-faint` |

### 1.1 中性阶（暖灰）

| Token | 值 | 典型用途 |
| --- | --- | --- |
| `--n-25` | `#fdfcfa` | 标签悬停底、极浅分区 |
| `--n-50` | `#faf9f7` | 面板底（原 `#fafafa`） |
| `--n-100` | `#f6f4f1` | 控件 hover 底 |
| `--n-150` | `#efede9` | 分隔细线、激活底 |
| `--n-200` | `#e7e4df` | 主描边 `--line` |
| `--n-250` | `#dad5ce` | 强调描边、禁用描边 |
| `--n-350` | `#c6c0b7` | 输入框 hover 边 |
| `--n-400` | `#b5afa6` | 占位图标、弱符号 |
| `--n-500` | `#a09a91` | 极弱文字 |
| `--n-600` | `#746f66` | `--text-faint` |
| `--n-700` | `#57524a` | `--text-muted` |
| `--n-800` | `#49443d` | 深色控件 |
| `--n-900` | `#302c27` | 深色控件 hover |
| `--n-950` | `#191714` | `--text`、正文与标题 |

画布 `--bg-page` 保持纯白 `#ffffff`，文档、代码、CSV、H5 四类查看器内容区因此仍是白纸；暖意只出现在面板底、描边和阴影里。阴影由冷调 `rgba(9,9,11,…)` 改为 `rgba(25,23,20,…)`，避免暖底上浮出灰蓝投影。

### 1.2 品牌（赤陶）

| Token | 值 | 用途 |
| --- | --- | --- |
| `--brand` | `#b5542c` | 主信号：图标、主按钮、选中条、激活下划线、链接描边 |
| `--brand-hover` | `#9d4522` | hover |
| `--brand-active` | `#853919` | active / 聚焦环 |
| `--brand-soft` | `#fbeee8` | 选中行、用户气泡底 |
| `--brand-soft-2` | `#f6e2d7` | 选中行 hover、文本选中 |
| `--brand-line` | `#eed3c5` | 浅色描边、分隔高亮 |
| `--brand-ink` | `#8f3b1b` | 浅底上的品牌文字（链接、选中文件名） |
| `--on-brand` | `#ffffff` | 品牌底上的文字 |

选橙不选正红：`#b5542c` 与火焰图标的暖度一致，又与失败态 `#b42318` 在明度、色相上都能分开。

### 1.3 语义色（与品牌分离）

| 状态 | 主色 | 浅底 | 描边 | 说明 |
| --- | --- | --- | --- | --- |
| 成功 / 已连接 | `#15803d`（`--success`、`--success-dot`） | `#f0fdf4` | `#bbf7d0` | 绿，不会被误读成品牌 |
| 警告 / 运行中 | `#8a6100` / `#6d4a00`（小圆点 `--warning-dot` = `#a16207`） | `#fdf6e4` | `#e3cf9a` | 琥珀，饱和度低于品牌 |
| 失败 | `#b42318`（强调 `--danger-strong` = `#d92d20`） | `#fef3f2` | `#fecdca` | 深红，配 ✕ 图标 |

文本、图标与 6px 状态圆点分列两档：文字用 `--success` / `--warning`，圆点等小图形用 `--success-dot` / `--warning-dot`，避免小尺寸下对比度不足。三态变量各自持有真实色值（不写成 `--x: var(--x)` 这类自引用，否则解析为空）。

失败态与品牌色的分工：**品牌 = 可以点的主路径，红 = 出错**。二者从不共享位置——按钮上是赤陶，状态条与 toast 上是深红。

## 2. 品牌色的白名单

只有下列位置使用品牌色，其余一律保持中性：

1. **顶栏图标**：20px 火焰标，颜色 `--brand`。
2. **文件树选中行**：`--brand-soft` 底 + `1px --brand-line` 内描边 + 左侧 `2px --brand` 竖条，文件名转 `--brand-ink` 并加 500 字重。
3. **标签激活**：底部 `2px --brand` 下划线（替换原深色 1.5px 线）。
4. **对话历史当前会话**：同文件树的浅底 + 内描边，标题 `--brand-ink`。
5. **用户消息气泡**：`--brand-soft` 底 + `--brand-line` 边；助手消息保持无底色。
6. **发送按钮**（可用态）：`--brand` 底 + 白字；禁用态回落到中性。
7. **主操作按钮**：新建/打开项目、创建项目、保存并关闭、确认、设置保存、树操作确认——全部 `--brand`，hover `--brand-hover`，active `--brand-active`。
   - hover / active 规则一律带 `:not(:disabled)`：禁用按钮悬停时保持 `--bg-panel` 底 + `--text-faint` 字，绝不浮现品牌赤陶。
8. **链接**：`--brand-ink`，下划线用 `--brand-line`，hover 加深下划线。
9. **输入区**：聚焦时 `--brand` 边 + `rgba(181,84,44,.16)` 光环。
10. **CSV 选中单元格**：`2px --brand` 内框。
11. **执行 trace 当前步骤**：圆点填充 `--brand`，标题 `--brand-ink`。
12. **分栏拖拽**：hover / 拖拽中指示线 `--brand-line`。
13. **文本选中**：`--brand-soft-2`。
14. **焦点环**：`--focus`（= `--brand`），替换基线里所有 `outline: 2px solid #09090b`。

## 3. 明确不染色的部分

- 顶栏、面板、状态栏的底色与描边：只用暖中性阶，避免整屏泛橙。
- 图标按钮、菜单项、标签非激活态：hover 仍是 `--n-100`，文字仍是 `--n-950`。
- 正文、数字、表格内容、代码 token：不动。
- 成功 / 警告 / 失败三态：各自语义色，禁止套用 `--brand`。
- 侧栏宽度、顶栏高度（52px）、标签高（38px）、输入框圆角（12px）、正文字号：与基线逐项一致。

## 4. 对比度实测

| 组合 | 比值 | 结论 |
| --- | --- | --- |
| `--n-950` on `#fff` | 16.6:1 | AAA |
| `--n-700` on `#fff` | 7.8:1 | AAA |
| `--n-600` on `#fff` | 5.0:1 | AA（弱化文字下限） |
| `--brand` on `#fff` | 4.9:1 | AA（正文级，可作按钮底） |
| `#fff` on `--brand` | 4.9:1 | AA（按钮文字） |
| `--brand-ink` on `#fff` | 7.1:1 | AAA（链接） |
| `--brand-ink` on `--brand-soft` | 6.1:1 | AA |
| `--danger` on `#fff` | 5.9:1 | AA |

品牌色不用于小于 12px 的细体文字；小图标除外（图形对比度 3:1 已足）。

## 5. 图标

- 来源：`backend/icons/128x128.png`（128×128，8-bit RGBA，单色火焰，透明底）。
- 处理方式：**只重写 RGB，完全保留 alpha**——形状、笔画宽度、内孔、留白比例一字未动，没有重绘、没有描摹成 SVG、没有为小尺寸改形。
- 交付文件（`assets/logo/`）：

| 文件 | 说明 |
| --- | --- |
| `chatfgm-logo-color.png` | `#b5542c` 实色，128px，**应用内实际使用** |
| `chatfgm-logo-brand.png` | `#8f3b1b` 深色版，浅底加深 / 印刷用 |
| `chatfgm-logo-inverse.png` | 纯白版，深色底反白用 |
| `chatfgm-icon.png` | 原始单色图标，保留为 alpha 掩模母版 |
| `preview.html` | 尺寸 20/24/32/48/128 与四种底色的对照页 |

- 放置：`#app-menu-button` 内、字标之前，20×20，与“ChatFGM”间距 8px；字标 15px / 600 / `letter-spacing: 0.01em` 不变，按钮左侧 −8px 视觉对齐不变，顶栏仍为 52px。
- 用 `<img>` 而不是 CSS `mask`：掩模写法在无头与部分导出链路里不渲染，位图导出更可靠。

## 6. 验证记录

- 工作台 1440×900 / 1000×800 / 800×860：三栏栅格、折叠按钮、标签条、六类查看器、对话与输入区、状态栏位置与基线完全一致；与基线 800×860 截图逐区比对无位移。
- 欢迎页 1440×900：仅主按钮、品牌图标变色，其余中性。
- 设置弹层：保存按钮为品牌色，取消按钮保持中性，禁用态沿用基线浅底。
- 选中态：文件树选中行、标签激活下划线、CSV 单元格、对话当前会话均已实测。
- 演示入口改为 `?demo=1` 才自动进入示例项目，默认进入空工作台。
- 语义色实测（Edge 无头 + CDP 读取 `getComputedStyle`）：成功圆点 `rgb(21,128,61)`、失败圆点 `rgb(180,35,24)`、停止圆点 `rgb(161,98,7)`、中性通知不显示圆点；状态条 `connected` 文字/圆核为绿 `#15803d`、`error` 文字与标记为红 `#b42318`、`connecting` 为 `--text-muted`。
- 禁用态悬停实测：真实 `:hover` 命中禁用主按钮与禁用发送按钮后，背景保持 `rgb(250,249,247)` / `rgb(239,237,233)`，不出现赤陶；可用主按钮 hover 正常转 `--brand-hover`（`rgb(157,69,34)`）。
- 样式块花括号配平（1026/1026）；除 `:root` 与 `#ffffff` 外，样式层已无颜色字面量，语义变量无自引用。

## 7. 已知项

- 无头浏览器不触发 `:focus-within`，输入框品牌聚焦环需在真实浏览器查看（CSS 已就位）。
- 品牌色以 CSS 变量承载；若走 PDF 导出，请确认导出链路保留 `var()` 解析结果再套印。
- 本轮未做深色主题；若后续要做，只需新增一组 `[data-theme="dark"]` 覆盖中性阶与 `--brand-soft/-line/-ink`，白名单位置不用改。
